# Рілс «Збери рілс з рандомних відео цього року»

1. Покладіть 40–55 своїх кліпів/фото в одну папку, назвіть по порядку: `01.mp4`, `02.mp4`, ...
   Перший кліп — інтро із заголовком (≈5.7 с), решта — по ≈1.1 с (шматок із середини кліпу).
2. Запустіть (потрібен ffmpeg):
   ```bash
   ./make_reel.sh ~/my_clips reel.mp4            # без музики — звук додати в TikTok
   ./make_reel.sh ~/my_clips reel.mp4 song.mp3   # з вашим аудіо
   ```
3. Налаштування: `TITLE="..."`, `TITLE_TOP="..."`, `INTRO=5.7`, `CUT=1.1`,
   `LYRICS=lyrics.txt` (формат рядка: `початок|кінець|English|Українською`, див. `lyrics_example.txt`).

Вихід: 1080×1920, 30 fps, легка кольорокорекція + віньєтка.
